# Live Engagement Coach Backend

## Quick start (Docker)

1. Copy `.env.example` to `.env` and fill values.
2. `docker compose up --build`
3. Open http://localhost:8000/docs

## Notes
- Service lives in `backend/`. Root is a short index.
- Codex session ID is required for submission (`/status` in Codex thread).
- Cursor use is not the required Codex evidence.
